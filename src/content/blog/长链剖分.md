## 引入
重链剖分的兄弟，都是把树的一些性质给发掘出来，然后根据这些性质来剖分树，将树分为便于维护的一段一段。  
与重链剖分不同的是，长链剖分是根据子树的最大深度而不是子树大小来剖分的。定义一个节点的儿子所在子树深度最大的儿子为深儿子。  
然后就和重链剖分一样先遍历深儿子，标上dfn序和一些别的信息。都可以使用两次dfs处理。  
## 性质
1.一个点的 $k$ 级祖先所在的长链长度至少为 $k$。  
2.一个节点 $u$ 所在长链一定比 $u$ 的轻儿子所在长链要长。因此有 $u$ 到根的路径上的轻边数量是 $\sqrt{n}$ 级别的。  

## 应用
长链剖分的一个重要应用就是 $\mathcal{O}(n\log n)$ （也可以做到 $\mathcal{O}(n)$ ）预处理，$\mathcal{O}(1)$ 回答一个点的 $k$ 级祖先。  
做法很有意思，代码细节也比较多。  
可以考虑先跳到 $2^m$ 级祖先，其中 $m=\lfloor \log k \rfloor$。然后到这个祖先所在长链的链头，此时我们要的 $k$ 级祖先一定是这个链头节点的不超过该长链链长级祖先或者在该长链上。预处理出相关信息就可以快速回答。正确性证明略。  
模板题[P5903 【模板】树上 K 级祖先](https://www.luogu.com.cn/problem/P5903)代码：
```cpp
#include<bits/stdc++.h>
using namespace std;

#define ll long long
#define ull unsigned long long
#define fi first
#define se second
#define mp make_pair
#define pb push_back
#define ui unsigned int
ui s;

inline ui get(ui x) {
	x ^= x << 13;
	x ^= x >> 17;
	x ^= x << 5;
	return s = x; 
}

const int MAXN=500010;
ll ans,tans;
int n,q,g,p,root,dfn[MAXN],nes[MAXN],pos[MAXN],e[MAXN],fa[MAXN],m[MAXN],d[MAXN],ls[MAXN],top[MAXN],f[20][MAXN];
vector<int> es[MAXN];


void dfs(int x){
    for (int e:es[x]){
        f[0][e]=x;
        d[e]=d[x]+1;
        dfs(e);
        if (m[e]>m[x]){
            ls[x]=e;
            m[x]=m[e];
        }
    }
    m[x]=max(m[x],d[x]);
}
void dfs2(int x,int z){
    dfn[x]=++p; pos[dfn[x]]=x; nes[dfn[x]]=z;
    if (es[x].empty()) return;
    top[ls[x]]=top[x];
    dfs2(ls[x],fa[z]);
    
    for (int e:es[x]){
        if (e==ls[x]) continue;
        top[e]=e;
        dfs2(e,e);
    }
}
int main(){
    ios::sync_with_stdio(false); cin.tie(nullptr); cout.tie(nullptr);
    cin>>n>>q>>s;
    g=log2(n);
    for (int i=1;i<=n;i++){
        cin>>fa[i];
        if (fa[i]) es[fa[i]].pb(i);
        else root=i;
    }
    d[root]=1;
    top[root]=root;
    dfs(root);
    dfs2(root,root);
    for (int i=1;i<=g;i++){
        for (int j=1;j<=n;j++){
            f[i][j]=f[i-1][f[i-1][j]];
        }
    }
    for (int i=1;i<=n;i++) e[i]=log2(i);
    for (int i=1;i<=q;i++){
        int x,k; 
        x=(get(s)^tans)%n+1;
        k=(get(s)^tans)%d[x];
        if (k){
            x=f[e[k]][x];
            k-=(1<<e[k])+d[x]-d[top[x]];
            x=top[x];
            if (k>=0) tans=nes[dfn[x]+k];
            else tans=pos[dfn[x]-k];
        }
        else tans=x;
        ans^=1ll*i*tans;
    }
    cout<<ans<<'\n';
    return 0;
}


```
