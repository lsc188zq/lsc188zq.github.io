## 引入
珂朵莉树（Chtholly Tree），又名老司机树 ODT（Old Driver Tree）。
这个数据结构的本质是维护颜色段均摊，即区间覆盖操作，通常使用平衡树std::set，std::map或者链表进行实现。

## 理论
设每次区间覆盖操作被完全覆盖掉的区间为 $k$ 个，新的颜色段只会增加 $1$ 个节点，那么珂朵莉树中的节点数目会变化 $-k+1$ 个。那么均摊下来珂朵莉树的时间复杂度为 $\mathcal{O}(m \log n)$ ，其中 $m$ 为操作次数， $n$ 为珂朵莉树中 最大区间个数。
## 实现
### 分裂
传入一个位置 $x$ ,将包含x的区间 $[l,r]$ 分裂为 $[l,x)$ 和 $[x,r]$ ，返回代表区间 $[x,r]$ 的节点的迭代器。这个操作直接用set自带的二分查找即可，比较简单，具体见代码。
### 区间覆盖
传入范围 $l$ ，$r$ 和覆盖值 $v$ 。类似无旋treap的思想，依次调用 $split(r+1)$ 和 $split(l)$ 然后把中间的节点删掉（过程中可以计算贡献），可以依次访问迭代器实现，最后插入代表新覆盖区间的节点就可以了。  
注意这里调用顺序，如果反过来可能会因为迭代器失效之类的事情出现问题。
### 注意
区间查询（不覆盖）的时间复杂度可以退化到 $\mathcal{O(n)}$。
## 代码

std::set实现
```cpp
struct cho{
    int l,r,v;
    bool operator<(const cho& b) const {
        return l<b.l;
    }
};

struct odt{
    set<cho> s;
    odt(){
        s.insert(cho{1,n+1,0});
    }
    auto split(int x){
        auto it=s.lower_bound(cho{x,0,0});
        if (it!=s.end()&&it->l==x) return it;
        --it;
        int l=it->l,r=it->r,v=it->v;
        s.erase(it);
        s.insert(cho{l,x-1,v});
        return s.insert(cho{x,r,v}).first;
    }
    void assign(int l,int r,int v){
        auto rit=split(r+1),lit=split(l);
        s.erase(lit,rit);
        s.insert(cho{l,r,v});
    }
};
```
