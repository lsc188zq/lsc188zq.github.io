### 1.题目简介
给出一棵 $n$ 个节点的树，以及一个空序列。

每个节点上有一个取值在 **0,1** 中的数。

每次你可以选择**没有父亲节点**的点删除，并且将这个节点上的数字放在当前数列末尾。

请你求出这个数列可能得到的**最小逆序对数**。

数据范围：$n \le 2 \times 10^5$

## 2.分析题目
观察题目，我们可以发现，**没有父亲节点**意味着结果一定是个拓扑序，
因为只有**0,1**,**最小逆序对数**则意味着要尽可能让多的$0$在数列前面

可以贪心地想到，如果有当前有没有父亲节点的 $0$ ，可以直接取走放在数列尾端，没有更优的情况。

所以，事实上我们可以将 $0$ 节点与它的父亲结点合并，若父亲节点取走，则它也可以被取走。
那么新的节点应该是一个储存了 $1$ 的数量和 $0$ 的数量的节点。

在此基础上，我们开始下一步的推导结论...

## 3.推导结论
假如现在有一个节点，先不考虑它本身，它有一些子节点(不考虑这些节点的子节点)，子节点 $i$ 的 $0$ 的数量记作 $a_i$ ，子节点 $i$ 的 $1$ 的数量记作 $b_i$。

现在有两个子节点 $j$ 和 $k$ ，假设最优情况是 $j$ 节点要刚好放在 $k$ 节点前面，那么我们可以使用  **微扰法** 来找出一个贪心策略。

由于 $j$ 和 $k$ 相邻，它们交换位置并不会影响其它节点对它们的影响和它们对其它节点的影响。

当 $j$ 节点在 $k$节点前时，$j$ 在 $k$ 前导致 $k$ 产生的代价应该为 $b_j \cdot a_k$ 。

同理，当二者位置反过来时，$k$ 在 $j$ 前导致 $j$ 产生的代价应该为 $b_k \cdot a_j$ 。

由于前者更优，那么有 $b_j \cdot a_k<b_k \cdot a_j$ ,进一步得到关系 $\frac{a_j}{b_j}>\frac{a_k}{b_k}$

那么我们就可以根据这一点给所有节点排序,特别的，若 $i$ 的 $b_i$值为 $0$ 则设其 $\frac{a_i}{b_i}$ 的值为正无穷。

若当前 $i$ 节点 的 $\frac{a_i}{b_i}$ 的值最大，很好证明不存在另外两个节点使得这两个节点合并后的节点 $v$ 的 $\frac{a_v}{b_v}>\frac{a_i}{b_i}$ 。

知道了这些贪心思想，我们就可以着手设计算法了。 

## 4.设计算法
我们可以建立一个大根堆存放所有节点，包括初始的 $0$ 节点，排序标准就不多说了。

那么当前的堆顶节点一定是最优的合成方案，可以将它与父节点合并，并将合并后的节点重新加入堆中，并统计过程中产生的代价。

一步步这样下来最终得到堆中只有一个节点时结束，具体可以用优先队列和\textbf{并查集}实现,要注意一些特殊情况。

这个过程可以理解为一个一步步逼近最优解的情况，取一个父节点时，目的就是为了取它下面的子节点，那么把最优的子节点与父节点合并，当要取父节点时把就可以把他们一起取出。

这样就能不断智慧地维护最优过程。

## 5.代码实现
```c++
    #include<bits/stdc++.h>
    using namespace std;
    #define ll long long
    struct node{
        ll x,a=0,b=0;
    };
    bool operator<(node x,node y){
        if (!x.b) return false;
        else if (!y.b) return true;
        else return (double)x.a/x.b<(double)y.a/y.b;
    }
    ll num[200010],out[200010],fa[200010],a[200010],b[200010];
    int find(int a){
        if (a==num[a]) return a;
        else return num[a]=find(num[a]);
    }
    priority_queue<node> q;
    int n,m;
    ll ans;
    int main(){
        ios::sync_with_stdio(0); cin.tie(0); cout.tie(0);
        cin>>n;
        for (int i=2;i<=n;i++) cin>>fa[i];
        for (int i=1;i<=n;i++){
            num[i]=i;
            int type; node e;
            cin>>type;
            if (type==0) e.a++,a[i]++;
            else e.b++,b[i]++;
            e.x=i;
            q.push(e);
        }
        while (q.size()!=1){
            node t=q.top();
            q.pop();
            if (out[t.x]) continue;
            int f=find(fa[t.x]);
            if (f==0) continue;
            out[f]=1;
            fa[t.x]=fa[f];
            num[f]=t.x;
            ans+=t.a*b[f];
            t.a+=a[f];
            t.b+=b[f];
            a[t.x]=t.a;
            b[t.x]=t.b;
            q.push(t);
        }
        cout<<ans;
    }
```
