题目小小地骗了一下，事实上题目大意就是要构造一个值域在 $[1,2n-1]$ 的整数序列，使得这个序列中有 $k$ 对成倍数关系的数。  
先考虑部分分，$k \leq 0$ 的性质无疑是十分抢眼的，这个可以直接输出从 $n$ 到 $2n-1$ 就可以了，因为要成倍数这里面的数一定是不行的，没有任何一对数能有至少两倍的关系。
这种构造题个人认为很重要的是要观察**特殊性质**，我们构造特殊性质的过程往往会对正解有所启发。  
发现样例 2 中 $k=3$ 即 $n(n-1)$ 输出了 $3$ 个一样的数，这时我们会发现，有 $a$ 个相同数时，会对答案有 $\frac{a \times (a-1)}{2}$ 的贡献。  
我们考虑**类似二进制拆分**的一个做法，从最大往下找，最后补一些单个的数（贡献为 $0$）。
考虑到可能不同的数之间会有影响，还记得特殊性质吗，我们选取的相同的数可以从 $[n,2n-1]$ 中找，就不会有冲突。  
但是这样还是会被卡，因为 $k$ 的范围可能导致至少需要的数超过 $n$，如何解决？  
我们想到最特殊的数 ——$1$，任何正整数都是它的倍数。那么我们可以通过 $1$ 来降低 $k$ 的范围以达到要求，就是只要可以就多搞几个 $1$。  
详情可以见代码：

```cpp
#include<bits/stdc++.h> 
using namespace std; 
#define ll long long 
const int MAXN=250010;
int n,m,p;
ll k,a[MAXN];
int main(){ 
	ios::sync_with_stdio(false); cin.tie(nullptr); cout.tie(nullptr);
	cin>>n>>k; p=n-1;
	for (int i=1;i<=n;i++) a[i]=1ll*i*(i-1)/2;
	for (int i=1;i<=n;i++){
		if (k>=a[i]+1ll*i*(n-i)){
			cout<<1<<" ";
			m++;
		}
		else{
			k-=a[i-1]+1ll*(i-1)*(n-i+1);
			break;
		}
	}
	if (m==n) return 0;
	for (int i=n;i>=1;i--){
		if (k==0) break;
		while (k>=a[i]){
			k-=a[i];
			++p;
			for (int j=1;j<=i;j++) cout<<p<<" ";
			m+=i;
		}
	}
	for (int i=m+1;i<=n;i++) {
		++p;
		cout<<p<<" ";
	}
	return 0;
} 
```
